# Plasmo Voice — Live Translate

Локальный перевод речи с профилем по умолчанию **русский → бразильский португальский**.
Установите JAR вместе с Plasmo Voice, Fabric API и Fabric Language Kotlin.
Распознавание речи и перевод выполняются **внутри процесса Minecraft**.

При первом запуске мод сам загружает модели в фоновом режиме:

- Whisper Base q5_1: примерно 60 МБ.
- TranslateGemma 4B Q4_K_M: примерно 2,49 ГБ.

Устанавливать Ollama, Python, отдельные исполняемые файлы или сервисы не требуется, так же как и запускать скрипты.
Когда модели будут готовы, перевод работает офлайн. Для Minecraft multiplayer
по-прежнему требуется соединение с сервером.

```text
Plasmo Voice → аудио PCM → встроенный Whisper.cpp (русский)
    → встроенный TranslateGemma (русский → португальский) → чат / облака
```

## Установка и первое открытие

1. Скопируйте `build/libs/pv-addon-livetranslate-1.0.0.jar` в `.minecraft/mods`.
2. Запустите игру. Мод загрузит модели в фоновом режиме; в игровом мире будет отображаться прогресс на экране.
3. Подождите сообщения о готовности моделей распознавания речи и переводчика.
4. Используйте Plasmo Voice → Addons → Live Translate, чтобы настроить языки, качество, чат и облака.

Рекомендуется выделить примерно 3 ГБ на диске для моделей, плюс место под саму игру. Модели хранятся
в `%USERPROFILE%\.livetranslate` в Windows (`~/.livetranslate` в Linux/macOS), в общей папке для разных launchers.
Загрузки выполняются через временные файлы, с точным размером и фиксированным SHA-256; неполный или повреждённый файл
никогда не будет загружен. Неудачная загрузка повторяется до трёх раз. Если проблема сохраняется, мод сообщит об этом;
перезапустите игру при наличии соединения, чтобы повторить попытку.

Аудио, расшифровки и переводы остаются на компьютере. Единственные сетевые соединения, которые делает мод,
— это GET-запросы для загрузки публичных весов моделей. Нет API перевода,
локального сервера, API-ключа или онлайн-резервного варианта. Если перевод не удался,
расшифровка отображается с префиксом `[original]`. Реплики не записываются в лог аддона.

## Русский → португальский

Начальный профиль фиксирует входной язык **Русский**, выходной **Португальский** и выбирает **Beam Search**.
Whisper распознаёт русский, а TranslateGemma переводит напрямую на pt-BR; промежуточного этапа на английском языке нет.
Фиксированный русский язык помогает избегать зависимости от определения языка в коротких фразах.

Этот дистрибутив включает нативные библиотеки для CPU. И Whisper, и перевод используют CPU и RAM;
RTX 4060 не используется встроенным рантаймом перевода. Работа идёт в фоновых потоках, а очередь ограничена,
чтобы отбрасывать устаревшие фразы. Скорость следует измерять на реальной речи и при запущенном Minecraft.

**Модель распознавания:** Base — стандартный вариант. Small может улучшить распознавание, но требует больше CPU;
при выборе этого варианта мод один раз загружает примерно 190 МБ и затем меняет модель в фоновом режиме.
Tiny делает упор на скорость. Модели `.en` предназначены только для английского и не подходят для русского.

Если результатом будет английский язык, Whisper может переводить напрямую, без этапа TranslateGemma.
Если входной и выходной языки совпадают, мод просто выполняет транскрипцию.

## Расширенная настройка

Старый файл `config/livetranslate.properties` игнорируется. Внешние провайдеры не настраиваются.
Параметры языка и стратегии локального профиля начинаются с русского, португальского и Beam Search;
остальные существующие настройки сохраняются.

| JVM property | Использование |
|---|---|
| `-Dlivetranslate.models.dir=...` | Папка со всеми моделями; по умолчанию `~/.livetranslate` |
| `-Dlivetranslate.whisper.dir=...` | Альтернативная папка только для Whisper |
| `-Dlivetranslate.whisper.model=base` | Выбор Whisper, переопределяющий меню |
| `-Dlivetranslate.whisper.model.path=...` | Явный локальный GGML-файл для Whisper |

`LIVETRANSLATE_MODELS_DIR` также задаёт общую папку. `LIVETRANSLATE_WHISPER_DIR` задаёт
только папку для Whisper. Старая папка `<gameDir>/livetranslate` по-прежнему проверяется.
Дополнительные GGML-модели и пользовательские библиотеки продолжают быть продвинутыми опциями;
автоматически скачиваются только tiny/base/small q5_1. Существующие файлы Whisper из более ранних версий могут быть переиспользованы.
Файлы `.bin` и `.gguf` не версионируются в репозитории.

## Разработка

Используйте JDK 25:

```powershell
.\gradlew.bat build
```

`whisper-jni` и `java-llama.cpp` включены в состав мода как библиотеки вместе с нативными файлами для поддерживаемых платформ.
Модели не находятся внутри JAR.

Обычные тесты используют небольшие симулированные модели и не скачивают веса ИИ.
Они покрывают маршрутизацию русский → португальский, кэширование, ошибки загрузки нативной библиотеки, неверные ответы,
интеграцию загрузки и проверку контрольной суммы. Чтобы явно проверить реальную модель:

```powershell
.\gradlew.bat translationSmoke
```

Эта команда скачивает модели в `build/smoke-models/`, загружает и освобождает Whisper,
а затем проверяет русский перевод с использованием именно встроенной нативной библиотеки.
Это не замена полноценного теста внутри Minecraft.

Если Gradle падает с ошибкой `Unable to establish loopback connection` в Windows:

```powershell
New-Item -ItemType Directory -Force build/tmp | Out-Null
$env:JAVA_TOOL_OPTIONS = "-Djdk.net.unixdomain.tmpdir=$PWD\build\tmp"
.\gradlew.bat build --no-daemon
```
